# AGENTS.md — go-otfp

## What this is

Pure Go library and CLI (`otprobe`) that identify which OT protocol a network endpoint speaks, with safe connection-level probes. Profile: **protocol-library**. The API is v0.

## Organisation standards

This repository follows **otfabric/engineering policy 1.2**, profile **protocol-library** (`.otfabric/policy.yaml`, mode `enforce`). Where this file and the organisation standards disagree, this file wins here — say so in your report.

## Hard rules

1. Never lower `COVER_MIN` (90), add lint suppressions, or skip or delete tests to make CI pass.
2. Safety contract: detection sends a handshake or one harmless request; identify uses the protocol's own read-only identity service. Never write, control or reconfigure a device.
3. The library stays dependency-free (standard library only). Never import a `go-<protocol>` library or an `*-interop` package from library or CLI code: they are for validation only.
4. Never claim interoperability beyond the evidence in INTEROPERABILITY.md.
5. `core.Protocol` constants are appended, never renumbered.
6. `protocols/enip/catalog.go` is generated by `make generate`; do not edit it.

## Definition of Done

`make check` green; tests for new behaviour including error paths; README.md and FINGERPRINTS.md updated for protocol changes; RELEASE.md section for user-visible changes; failing or skipped steps reported.
